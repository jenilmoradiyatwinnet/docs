  ### More accurate Android session tracking

  Resolved lifecycle-related issues that could affect session duration and
  active-user calculations.

  **Release type:** Patch release

  - **Duplicate sessions:** Prevented multiple sessions from being created during rapid foreground and background changes.
  - **Session duration:** Improved start and end-time handling for more accurate duration calculations.
  - **Background activity:** Prevented inactive application time from being counted as active usage.
  - **Lifecycle ordering:** Improved the order in which SDK lifecycle events are processed.
</Update>
