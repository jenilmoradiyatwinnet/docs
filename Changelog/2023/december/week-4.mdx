  ## First realtime analytics experience

  Twinalyze introduced its initial realtime analytics experience, allowing
  product activity to be viewed as it happened.

  ### Realtime analytics

  - Added the first Realtime page
  - Introduced live visibility into incoming product activity
  - Created the foundation for realtime user and session monitoring
  - Prepared the dashboard for live analytics updates

  ### Initial Android SDK

  - Introduced the first Twinalyze Android SDK foundation
  - Enabled Android applications to connect with the Twinalyze platform
  - Prepared mobile applications to send analytics activity
  - Established the base for future event, session, user, and device tracking

  This release connected the Twinalyze platform with Android applications and
  introduced the first live analytics experience.
